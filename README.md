# Secret Love Cipher | DevArea

Welcome to the **Secret Love Cipher** project!

---

## About This Project
This is a fun and creative web-based cipher tool designed for encoding and decoding secret messages with a touch of love and mystery. The project is built with HTML, CSS, and JavaScript, and features a beautiful, modern UI.

- **Live Demo & Source:** [DevAreaYT/Secret-Love](https://github.com/DevAreaYT/Secret-Love)
- **Main File:** `index.html`

---

## How to Use
1. Open `index.html` in your browser.
2. Type your message in the input area.
3. Use the toggle to switch between encoding and decoding modes.
4. Copy the result and share your secret message!
